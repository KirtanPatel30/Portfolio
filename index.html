Fraud Detection MLOps Pipeline live ↗ repo ↗
Python · FastAPI · XGBoost · Docker · GitHub Actions

Situation: most ML projects stop at a trained model with no plan for what happens once it's live. Task: build the full production lifecycle a real ML team would need around a fraud-detection model — not just train one. Action: served the model behind a FastAPI + Docker layer, logged every prediction to SQLite, and implemented statistical drift detection (PSI + Kolmogorov–Smirnov test) that automatically flags when live traffic diverges from training data and triggers retraining with an old-vs-new metrics comparison, all wired through GitHub Actions CI/CD. Result: a self-monitoring ML system deployed live, not a one-off notebook — recruiters can query the working API directly.

$ python -m monitoring.drift_detection
✓ drift detected: PSI ≥ 0.25 on 6/8 features
✓ retrain triggered → new model F1: 0.827 (was 0.752)
→ live: ml-ops-fraud-pipeline.onrender.com/docs
